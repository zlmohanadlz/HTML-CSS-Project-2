## 📖 Overview

This is a **responsive and mobile-friendly website template** built using **HTML, CSS, and a bit of JavaScript**.  
The design is inspired by the **Kasper template**, featuring modern layouts, clean typography, and multiple sections like services, portfolio, about, pricing, and contact.

The project is part of my journey to practice **front-end web development** and improve skills in:

-   Semantic HTML5 structure
-   CSS3 layout (Flexbox & Grid)
-   Responsive design techniques
-   Accessibility improvements
-   DOM manipulation with JavaScript

---

## ✨ Features

-   🎨 **Modern & Clean Design** with smooth layouts.
-   📱 **Fully Responsive** (works on desktop, tablet, and mobile).
-   🖼️ **Portfolio Gallery** with filtering options.
-   🎥 **Video Background Section**.
-   📊 **Statistics & Skills Progress Bars**.
-   💳 **Pricing Plans Section**.
-   📬 **Contact Form & Newsletter Subscription**.
-   🌍 **Cross-Browser Compatibility**.
